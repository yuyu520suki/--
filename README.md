## 📌 项目简介

本项目是一款利用**遗传算法 (Genetic Algorithm)** 驱动的钢筋混凝土(RC)多层框架结构自动化优化设计系统。独立开发完成，总代码量约 7,200 行。

该系统致力于解决传统结构设计中"凭经验初选截面、人工反复试算调改"的设计痛点。它以**结构综合造价最小化**为优化目标，在严格遵循最新国家标准（GB 55001-2021等十余部规范要求）的前提下，实现承载力验算、拓扑构造约束检查的全面自动化。

> **学术/工程价值**：通过构建 "6基因分组编码" 和 "动态自适应遗传参数" 的核心算法，该系统不仅大幅提升了设计效率，在典型算例测试中，相较于传统的经验设计方案，能够**降低约30%的结构材料造价**。

## 🚀 核心系统特性

本项目不仅是一个算法 Demo，而是一个涵盖**力学建模、自动分析、优化求解、图表输出**全工作流的完备工程计算软件。

### 1. 进阶级遗传优化引擎

* **工程语义驱动降维**：首创 "6基因分组编码"（顶/底/标准层的柱，屋面/标准层的梁等分组），将 $77^N$ 的指数级搜索空间有效降维至 $77^6$ 级别，符合工程实际施工逻辑。
* **状态感知自适应控制**：算法不仅静态运行，还实现了根据当前种群收敛进度、可行解比例动态调节 `变异率 (Pm)` 和 `惩罚系数 (λ)` 的闭环反馈机制，有效避免早熟收敛。
* **进程级并发提速**：针对 Python GIL 的性能瓶颈，自主实现 `独立工作者 (Independent Worker)` 并行计算模型，核心验算阶段实测获得 **5.7x 的计算加速比**。

### 2. 精密结构力学分析与验算

* **参数化有限元建模**：底层集成并深度封装了 `anaStruct` 轻量有限元库，支持依据结构跨度、层高等参数全自动建立 2D 刚架力学分析模型。
* **规范级荷载包络分析**：内置符合 GB 55001-2021 的最新荷载组合逻辑。支持恒活载、雪/风荷载、及基于底部剪力法（GB 50011-2010）的地震作用水平力计算，抽取最不利内力包络设计。
* **严苛的边界验算**：支持70余种截面内置库。全面实现了受弯承载力、斜截面受剪承载力计算，并在柱验算中采用**控制点算法生成高精度 P-M 相互作用边界曲线**。

### 3. 一站式 GUI 与 自动化报表

* **轻量化可视化终端**：自带基于 `Tkinter` 编写的用户图形交互界面，支持实时查看优化迭代曲线、参数动态调整。
* **生产级文档生成**：支持一键导出详尽的 Word 结构计算说明书、Excel 敏感度分析报表、内力分布图与 P-M 曲线验算图纸。

## 💻 快速运行项目

该项目不依赖商业有限元软件(如 SAP2000, YJK 等)，可在任意标准 Python 环境开箱即用。

### 1. 环境依赖配置

```bash
# 推荐使用 Python 3.9+ 
pip install pygad anastruct matplotlib pandas python-docx openpyxl numpy
```

### 2. 拉起系统

```bash
# 启动带有完整参数面板的 GUI 图形客户端 (推荐)
python run_gui.py

# 或是以静默计算模式运行核心优化流
python main.py
```
